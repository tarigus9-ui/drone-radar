# رادار الدرون — تنصيب سيرفر خاص لعميل (من فلاش، بدون إنترنت)

كل عميل يحصل على **نسخة منفصلة تماماً**: سيرفر خاص به، قاعدة بيانات خاصة، مفاتيح خاصة، وشهادة أمان خاصة.
لا يمر أي شيء عبر سيرفراتنا ولا يُشارك مع عميل آخر.

## ما على الفلاش
| الملف | الوظيفة |
|---|---|
| `install.sh` | ينصّب سيرفر العميل خطوة بخطوة |
| `images.tar.gz` | كل برامج السيرفر (Docker) — لا حاجة للإنترنت |
| `supabase/` | إعدادات قاعدة البيانات والخدمات |
| `sql/` | جداول وصلاحيات رادار الدرون |
| `app/DroneRadar.apk` | تطبيق الهاتف (نسخة العملاء) |
| `backup.sh` | نسخة احتياطية يومية |

## متطلبات سيرفر العميل
- لينكس (Ubuntu 22.04 أو أحدث)، 4 معالجات، 8 جيجا رام، 100 جيجا تخزين.
- Docker مثبّت (Docker Engine + Compose 2.24 أو أحدث).
- عنوان ثابت على شبكة العميل (IP أو اسم) تصل إليه هواتف الحراس — داخل الشبكة أو عبر VPN.
- سيرفر واحد لكل عميل.

## التنصيب (10–15 دقيقة)
```
cd /media/USB/droneradar
sudo ./install.sh --name "Emaar" --host 10.20.0.5 --admin security@emaar.ae
```
في النهاية يطبع البرنامج:
- **رمز QR** للهواتف (وملف `setup-qr.png`).
- ملف `credentials.txt` فيه كلمة مرور المدير الأول وكل المفاتيح — **احفظه في مكان آمن**.

## ربط الهواتف
1. ثبّت `app/DroneRadar.apk` على الهاتف.
2. افتح التطبيق ← يطلب **مسح رمز الإعداد** ← امسح الـ QR.
3. المدير يدخل ببريده وكلمة المرور من `credentials.txt` ثم يغيّرها.
4. المدير ← **إدارة** ← يضيف المنشآت ← **+ دعوة موظف** لكل حارس ← يرسل له الرمز.
5. الحارس ← "إنشاء حساب جديد" ← يدخل رمز الدعوة ← يُضاف تلقائياً لمنشأته.

## الأمان
- الاتصال مشفّر بشهادة خاصة بالعميل، والهاتف **لا يثق إلا بهذه الشهادة** (مثبّتة في رمز الإعداد).
- لا تسجيل بدون رمز دعوة من المدير.
- بيانات الكشف تُحذف تلقائياً بعد 180 يوماً (قابلة للتعديل).
- نسخة احتياطية يومية في `/var/backups/droneradar/`.

## تجهيز فلاش جديد (لنا، على جهاز فيه إنترنت)
```
./deploy/make-flash.sh /media/USB  DroneRadar-client-release.apk
```
